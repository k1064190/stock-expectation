External Repo Benchmark

Why

Prediction quality deteriorated from 73% to 51% win-rate over six weeks. Three external open-source trading systems were cloned and analyzed in depth to surface transplantable improvement patterns.

What
  • Cloned three repositories into research/external/ (gitignored): Vibe-Trading (HKUDS), AutoHedge (Swarm Corp), FinceptTerminal (Fincept).
  • Three parallel sub-agent analyses produced per-repo reports at reports/external-analysis/{vibe-trading,autohedge,finceptterminal}.md.
  • Consolidated synthesis at reports/external-analysis/SYNTHESIS.md — improvements S1–S13 mapped against measured deficiencies.
  • Review gate outcome: only Tier 1 (S1 + S2 + S3) scheduled for Stage 1; remainder deferred.
How

License verification first: Vibe-Trading = MIT (code reuse permitted), AutoHedge = MIT (ideas only, architecture differs), FinceptTerminal = AGPL/commercial (ideas only, no code copying allowed). Adoption criteria required direct fit with Python CLI + Claude skills + SQLite track-record stack. Web UI, futures/crypto engines, C++/Qt, and ML platforms were excluded.

Code Locations

research/external/* (gitignored)   reports/external-analysis/*.md   .gitignore (research/external added)

Retrospective

WebFetch reconnaissance → clone → parallel sub-agent reports → synthesis was an efficient flow. Concretely measured deficiencies (BEAR 6%, 0%-signal types, constant confidence) gave clear priority ordering for candidates. Deferred items are preserved in SYNTHESIS.md for easy re-entry in future stages.
