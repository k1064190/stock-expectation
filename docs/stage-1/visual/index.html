Stage 1

Implemented Tier 1 improvements targeting three measured core deficiencies: signal significance testing (S1), risk gate hardening (S2), and confidence recalibration (S3).

Tier 1 Signal Gate Recalibration

Why

Three measured core deficiencies demanded direct fixes: valuation/cycle/mean_reversion signal types sitting at 0% win-rate with no pruning mechanism (S1); 39% LIVE low-quality predictions and BEAR over-generation at 6% (S2); confidence locked near 0.60 as a constant carrying no information (S3). Sources: Vibe-Trading (MIT) signal IC/classification and recalibration philosophy; AutoHedge risk-first gate approach.

What
  • S1: Added per-signal binomial p-value against the 50% null hypothesis plus a verdict (alive/weak/dead). Real data correctly identified valuation/cycle/mean_reversion as dead (p=0.001); remaining signals flagged weak.
  • S2: Added risk/edge gates to /expect and daily-briefing prompts (reward:risk < 1.5 blocks registration); raised the BEAR bar (≥3 signals + macro confirmation + RR ≥ 2.0; LIVE demoted to NEUTRAL).
  • S3: Fit a monotone recalibration map (isotonic/PAVA) to the calibration curve and applied it. Real data corrected over-confidence from 0.626 to 0.50. recalibration_map exposed in CLI calibration output.
How

_binomial_two_sided_p uses math.comb with no added dependencies. _signal_verdict feeds into get_signal_performance, which now returns p_value and verdict as defaulted fields — fully backward-compatible with existing consumers. _isotonic_nondecreasing (PAVA) drives build_recalibration_map and apply_recalibration (linear interpolation; empty map falls back to identity). find_worst_signals strengthened to filter on verdict == "dead". TDD: 9 new tests; full not-network suite at 287 passing.
