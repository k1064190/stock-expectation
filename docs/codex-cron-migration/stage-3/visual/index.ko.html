배포 및 검증 완료: Codex 전용 crontab은 활성 일정 12개와 검증된 롤백 지점을 모두 유지합니다.

실제 Crontab 배포

왜

실제 crontab은 두 저장소 구현을 모두 검토, 병합, 배포한 뒤에만 Codex 전용으로 전환해야 했으며, 관련 없는 모든 일정과 검증된 롤백 지점을 유지해야 했습니다.

무엇을

  • 변환 전에 128줄의 실제 crontab을 백업하고 롤백 및 후보 파일을 모두 600 모드로 영구 저장했습니다.
  • 세 일일 브리핑을 모두 codex-cli로 설정한 후보를 렌더링했습니다.
  • 주석 처리된 Claude 및 Anthropic API 대체 블록을 제거했습니다.
  • 금 작업은 --llm-mode codex-cli를, 할인 정보 작업은 DEALS_COLLECTORS=codex를 명시적으로 사용하도록 했습니다.
  • 관련 없는 Gemini 비디오 파이프라인과 pure-Python 작업을 포함해 활성 일정 12개를 모두 유지했습니다.
  • 주식 커밋 bb4c6186a7d9bcef045aade1810e5776e80605c3과 할인 커밋 17671c3b0b0132183b5d135f46a7c6c9f2864b41을 병합하고 배포했습니다.
  • 실제 crontab이 여전히 백업과 바이트 단위로 일치함을 확인한 뒤 2026-07-20 KST에 후보를 설치했습니다.
  • 설치된 crontab이 후보와 정확히 일치하고 활성 작업 12개를 유지하며 Claude, Anthropic 또는 --mode api 참조가 없음을 검증했습니다.
