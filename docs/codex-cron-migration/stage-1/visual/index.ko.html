1단계

예약된 주식 분석 작업이 이제 마이그레이션된 모든 작업에서 명시적이고 테스트 가능한 단일 Codex 실행 경로를 사용합니다.

Stock Schedulers

왜

Cron으로 실행되는 주식 분석에는 여전히 실행 가능한 Claude CLI 및 Anthropic API 경로가 있었습니다. 예약 작업이 조용히 Claude로 대체되지 않도록, 이번 마이그레이션에는 명시적이고 테스트 가능한 단일 Codex 실행 경로가 필요합니다.

무엇을

  • 높은 추론 수준의 gpt-5.6-sol을 기본값으로 사용하면서 CODEX_MODEL 재정의를 유지하는 공용 비대화형 Codex 실행기를 추가했습니다.
  • 일일 브리핑, 심층 분석, ISA 브리핑, 금 추세 및 뉴스 버킷 감사 실행을 해당 실행기로 마이그레이션했습니다.
  • capstone-readiness Cron 알림의 담당자 전달 지점이 Codex를 가리키도록 변경했습니다.
  • 스케줄러의 Claude/API 모드 선택과 Anthropic 선택적 의존성을 제거했습니다.
  • Codex 전용 실행을 설명하도록 crontab 템플릿과 운영자 문서를 업데이트했습니다.
  • 실행 가능한 Claude 패턴을 거부하고 정확한 Codex 명령 계약을 검증하는 회귀 테스트를 추가했습니다.

어떻게

테스트를 먼저 작성해 기존 Claude 경로에서 실패하는 것을 확인했습니다. 그런 다음 scheduler/codex_runner.py에 서브프로세스 동작을 중앙화하고, 해당하는 기존 프롬프트 및 fail-open 동작을 유지하면서 더 이상 필요하지 않은 실행 분기만 제거했습니다. 검증에는 집중 테스트 115개, CLI 도움말/가져오기 검사, 실시간 읽기 전용 및 workspace-write gpt-5.6-sol 스모크 호출, 전체 오프라인 테스트 958개가 포함되었으며 모두 통과했습니다.

회고

CLI 계약을 중앙화하여 누락을 기계적으로 감지할 수 있게 되었습니다. 자체 검토에서는 오래된 capstone 담당자 전달 문구를 찾아 수정했습니다. Antigravity가 지적한 모델 재정의 문제를 수정했습니다. --full-auto 관련 지적은 현재 CLI가 확인 요청 없이 실제 workspace-write shell 호출을 완료했고 해당 플래그를 목록에 표시하지 않았으므로 기각했습니다. Antigravity의 재검토에서는 지적 사항이 없었습니다. 로컬 Claude CLI가 인증되지 않았기 때문에 Doctor Cho가 2026-07-19에 이 마이그레이션의 Claude 검토를 명시적으로 면제했습니다.
