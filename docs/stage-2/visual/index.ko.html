Bear Sign Gate Dedup

왜

920건 전수 분석에서 구조적 버그·데이터 오염이 드러났습니다: outcome_return 부호 버그(BEAR HIT 음수, MISS 양수) → 모든 수익률 지표 오염; LIVE BEAR 승률 0%인데 계속 생성; 같은 종목 하루 18행 중복; analysis_group_id 미사용.

무엇을
  • 2.1 BEAR 부호: outcome_return을 포지션 수익률로 재정의 (BEAR = −price_change). BULL/NEUTRAL 불변.
  • 2.2 store 게이트: insert_prediction이 LIVE + BEAR 거부, 같은 6키 OPEN 중복 거부. 부분 UNIQUE 인덱스로 동시성 백스톱.
  • 2.3 group_id: daily-briefing 프롬프트에 종목별 --analysis-group-id 지침 추가.
  • 2.4 백필: 1회성 마이그레이션으로 과거 BEAR 부호 반전 + 동일-6키 중복 제거. 백업 후 실행.
어떻게

evaluate_prediction: signed = -pct_change if BEAR else pct_change. 중복 키 = (ticker, market, direction, timeframe, source, date(created_at)) — live 가드·마이그레이션·UNIQUE 인덱스 3곳 모두 동일 키(entry_price 제외). 마이그레이션: 원자적 BEGIN/rollback 트랜잭션, _migrations 마커로 재실행 차단, SQLite Connection.backup()로 WAL 포함 일관 백업. TDD 전체 not-network 293 통과. 실DB: 920→732행(중복 188개 제거), BEAR 부호 반전 38건.
