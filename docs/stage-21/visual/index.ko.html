21단계

GDELT 및 와이어 서비스 RSS를 통한 글로벌 거시경제·지정학적 뉴스 통합 및 일일 브리핑 주입.

Macro News

왜

종목별 뉴스 피드(미국은 Finnhub, 한국은 Naver Search)는 전쟁(예: 호르무즈 해협 위기), 유가/에너지 충격, 중앙은행 서프라이즈, 관세 등 시장 전체에 영향을 미치는 세계적 뉴스를 놓칩니다. 기존에는 거시경제 맥락이 LLM의 학습 지식(컷오프 이후 오래된 정보)과 예정된 경제 캘린더에서만 제공되었습니다. 심층 리서치를 통해 GDELT(무료, API 키 불필요)가 최적의 글로벌 소스이며, 와이어 서비스 RSS가 키 없이 사용할 수 있는 신뢰할 만한 대안임을 확인했습니다.

무엇을

  • mcp-market-data/macro_news.py — 시장 무관 거시경제 뉴스 페처:
    • fetch_macro_news — GDELT DOC 2.0 artlist (User-Agent, TTL 포함 파일 캐시 및 오류 시 stale 제공, GDELT의 1요청/5초 제한을 준수한 재시도).
    • fetch_rss_macro_news — 키 없는 와이어 RSS (BBC business/world, CNBC economy, Yonhap English): 중복 제거, 엄격한 tz-aware since_days 컷오프, 발행 시각 기준 정렬, 피드별 오류 시 건너뜀.
    • get_macro_news — (items, source)를 반환하는 오케스트레이터.
  • stock-cli macro-news — --timespan / --limit / --query, JSON 출력.
  • scheduler/daily_briefing.py — _macro_block()을 미국 및 한국 프롬프트에 주입 (오류 발생 시 ""로 저하, 브리핑을 블로킹하지 않음).
  • 캐시 디렉터리 data/cache/는 gitignore 처리. API 키 불필요.

어떻게

RSS를 기본, GDELT를 폴백으로 사용 — 초기 계획에서 역전된 구성으로, 실운영 결과에 근거합니다. GDELT는 이 호스트의 공유 IP에서 빈번하게 429 오류를 반환하고(1요청/5초, 다른 트래픽과 경합) 광범위한 다국어 쿼리가 노이즈가 많은 비관련 결과를 반환하는 반면, RSS 와이어는 안정적이고 영문이며 편집자가 큐레이션합니다. GDELT(영어 전용, 단일 OR 그룹 쿼리)는 RSS에서 결과가 없을 때만 사용합니다. TDD로 개발(거시경제 테스트 13개 + 일일 브리핑 연결 테스트 2개), 전체 스위트 662개 통과.

리뷰 루프

  • code-reviewer-pro: 치명적 오류 0건 / 경고 0건 — "그대로 배포"; 2개의 제안사항 (RSS 정렬 안정성, 날짜 누락 폴백)은 Codex의 RSS 마이너 사항과 겹쳐 함께 적용되었습니다.
  • Codex (gpt-5.5, high): [주요] GDELT 쿼리가 OR 그룹을 추가 외부 괄호로 감쌌음 — GDELT는 중첩 OR 그룹을 금지하므로 외부 괄호를 제거. [마이너] 캐시가 잘못된 형식의 JSON만 처리하고, 형태가 잘못된 유효한 JSON은 처리하지 못함 — _read_cache가 비-딕셔너리를 거부하도록 수정; _cache_is_fresh/_items_from_cache가 타입 오류를 포착하여 손상된 캐시를 없는 것으로 처리. [마이너] RSS의 pubDate 누락/오류 시 컷오프를 우회하고 날짜 문자열 정렬이 시간을 무시함 — 파싱 가능한 날짜를 필수로 요구하고 tz-aware datetime 기준으로 정렬.
  • Gemini: 사용 불가 (무료 티어 CLI 지원 중단).

회고

실운영 테스트가 설계를 바꿨습니다. 리서치에서 "GDELT이 최고의 무료 소스"라는 결론은 추상적으로는 맞았지만, 통합 결과(공유 IP에서의 지속적인 429 오류 및 다국어 노이즈)로 인해 편집자 큐레이션 RSS가 더 나은 기본 소스가 되었습니다. 교훈: 선택한 소스를 사양만이 아닌 실제 런타임 환경에서 검증해야 합니다. GDELT의 점진적 저하(캐시, stale 제공, 빈 응답이 크래시 유발 안 함) 덕분에 스로틀이나 장애가 발생해도 브리핑이 차단되지 않습니다 — 처음부터 복원력을 내장한 가치가 입증된 것입니다.
