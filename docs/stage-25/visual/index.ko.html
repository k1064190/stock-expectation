25단계

금 매수 타이밍과 장기 거시 편향을 점수화하여 ACCUMULATE / HOLD / PAUSE 판정을 내리는 주간 스케줄 작업.

Gold Weekly Trend

왜

Doctor Cho는 KRX 금현물(실물 골드, 2g 보유)에 정기적으로 분할 매수하고 있으며, 기존 주식 crontab 작업처럼 매주 반복되는 체크포인트를 원했다 — 이번 주 분량을 추가하기에 지금이 합리적인 시점인지, 그리고 금이 장기적으로 구조적 상승 편향을 갖는지 두 가지 질문에 답하기 위해서다. 배경이 된 심층 리서치(WGC / IMF / Fed / J.P. Morgan, 2026-07-03)는 스코어카드의 근거가 되는 거시 사실을 확립했다: 중앙은행 매수는 구조적으로 높은 수준(2022년 이후 연 ~1,000톤, 이전 10년간 연 ~500톤 대비)이며, 역사상 최악의 금 약세장은 Volcker식의 징벌적 실질금리(~5–8%, 현재는 부재)를 필요로 했고, "달러 붕괴" 서사는 과장되어 있다(USD 준비통화 비중 ~58%, 2022년 이후 횡보).

무엇을

  • 결정론적 기술 점수(주간 진입 타이밍): MA50/MA200 대비 추세, 52주 고점 대비 낙폭, RSI 밴드
  • 결정론적 거시 스코어카드(장기 편향): 중앙은행 매수 + 실질금리 국면 + 달러의 구조적 변화 + FX(원/달러), 실시간 데이터와 분기별로 갱신되는 설정 파일을 바탕으로 Python 규칙에 따라 점수화
  • 선택적인 claude -p 한국어 요약 문단 1개(fail-open)
  • 선택적인 근사 개인 2g 포지션 손익 라인(spot USD/oz × 원/달러 ÷ 31.1035, "근사"로 표기)
  • 주간 변화 추적을 위한 12주 롤링 상태(state/gold_trend.json) — predictions.db는 사용하지 않음
  • 판정: 하드 PAUSE 플래그(RSI > 75, 실질금리 징벌적 수준, 또는 수동 risk_off 킬스위치)가 있으면 우선 적용; 그렇지 않고 macro ≥ 55이고 technical ≥ 50이면 ACCUMULATE; 그 외에는 HOLD

어떻게

config → technical → macro → verdict → rendering → state → fail-open fetchers → orchestration의 8개 TDD 작업으로 구축했으며, 서브에이전트 기반 개발 방식을 사용했다: 작업마다 새로운 구현 에이전트, 작업마다 스펙 및 품질 리뷰, 이후 브랜치 전체 리뷰. Fetcher들은 fail-open 방식으로 동작하여 실패 시 sentinel 값을 반환하고, build_context가 이를 라벨이 붙은 저하(degraded) 라인으로 변환하며, 리포트는 최선 노력으로 Telegram 전송을 시도하기 전에 디스크에 먼저 기록된다. 매주 일요일 21:00 KST에 실행된다. 첫 실전(live) 드라이런에서 하나의 캘리브레이션 결정이 드러났다: 실질금리 restrictive_above_pct (2.0)가 원래 서브 점수 하한선과 하드 PAUSE 거부권 두 가지 역할을 동시에 수행하고 있어서, 실제 DFII10 ≈ 2.2%가 리서치 결과와 모순되게 매수(ACCUMULATE)를 강제로 PAUSE시켰다. 두 역할을 분리하여 restrictive_above_pct(2.0)는 서브 점수 하한선만 담당하고, 새로 추가된 punitive_above_pct(3.5)가 하드 PAUSE 거부권을 담당하도록 변경했다. 변경 후 드라이런은 2.2%에서 ACCUMULATE를 반환한다.

회고
