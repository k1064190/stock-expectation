15단계

진입 구간 내에 수익 발표나 고영향 매크로 이벤트가 존재할 때 진입을 차단하거나 신뢰도를 낮추는 결정론적·페일-오픈 이벤트 리스크 게이트(R3)를 도입합니다.

Catalyst Event Gate

왜

/expect 점수(ALGO + NEWS + LLM_CONTEXT)와 R1(레짐) / R2(과확장) 게이트는 모두 상태(state) 기반이어서 날짜가 정해진 이진 이벤트를 인식하지 못합니다. 기술적으로 강하고 매크로가 뒷받침되는 셋업이라도, 다음 거래일이 수익 발표일이거나 Fed 결정일이라면 잘못된 진입입니다. 결과는 논리적 테제가 아닌 동전 던지기 갭이 됩니다. R3는 이 맹점을 결정론적·페일-오픈 이벤트 리스크 게이트로 해소합니다.

무엇을

  • 두 FMP 캘린더를 통합한 선행 촉매 타임라인: /earning_calendar(종목별 수익 발표, US 상장 종목 한정)와 /economic_calendar(시장 전반 고영향 매크로: FOMC / CPI / NFP).
  • RULE R3 게이트(EventGate): 종목별 수익 발표 캡/트림(US) + 시장 전반 매크로 트림(US + KR). KR은 매크로 전용 — US 매크로 스트림을 소비(FX / SOXL 경유 전달)하지만 종목별 수익 발표 캡은 없음(FMP에 KR 선행 EPS 피드 없음).
  • CLI: bin/stock-cli catalyst timeline TICKERS --market {US,KR} [--days 14] [--include-macro] 및 bin/stock-cli catalyst gate TICKERS --market {US,KR}.
  • 타임라인 구조, R3 규칙 테이블, CLI, KR-vs-US 매트릭스, R1+R2+R3 스태킹을 문서화한 신규 catalyst-event-gate 스킬.
  • /expect 연동: Step 4 촉매 게이트 fetch, Step 7 게이트 섹션의 RULE R3, ALGO 'Earnings event' 행을 R3가 공급.
  • R3 임계값(거래일): 수익 발표 td <= 2이면 레이블을 WATCH로 캡; 2 < td <= 5이면 신뢰도 0.05 트림; td > 5이면 적용 없음. 고영향 FOMC/CPI/NFP가 td <= 2 이내이면 해당 시장의 모든 종목에 macro_trim 0.05 적용.
  • 스태킹: R1/R2/R3 중 어느 하나의 WATCH 캡이라도 존재하면 해당 레이블이 확정; 신뢰도는 가장 엄격한 캡 순으로 하향 조정된 뒤 R3 트림이 추가 적용; R3는 BUY 기준을 올리지 않음(R1/R2만 올릴 수 있음).

어떻게

  • 순수 코어는 stdlib 전용에 fetcher 주입 가능하므로 R3 로직 전체를 오프라인으로 테스트: build_timeline / evaluate_gate는 선택적 fetch_earnings / fetch_macro 콜러블을 받음(기본값은 실제 httpx FMP 래퍼; 테스트는 스텁 전달).
  • trading_days_between은 월–금 경계를 카운트(당일 = 0, 주말 인식). 공휴일은 의도적으로 무시 — 문서화된 주의사항; 유일한 영향은 이벤트가 ~1일 더 멀어 보이는 것으로, 페일-오픈 리스크 게이트에서는 안전한 방향.
  • 할당량 보호: evaluate_gate / CLI는 수익 + 매크로 윈도우를 호출당 한 번만 fetch하고 모든 종목을 메모리 내에서 순회(FMP 무료 티어 250회/일). KR은 수익 fetch를 전부 건너뜀.
  • FAIL-OPEN은 mcp-market-data의 나머지 컨벤션을 따름: FMP_API_KEY가 없거나 fetch 예외 발생 시 캡/트림이 없는 중립적 EventGate(gate_unavailable=True)를 반환하며, CLI는 여전히 exit 0으로 종료.

코드 위치

  • mcp-market-data/events.py — CatalystEvent, EventGate, trading_days_between, build_timeline, evaluate_gate, 임계값, 그리고 thin _fetch_earnings_window / _fetch_macro_window httpx 래퍼.
  • stock_cli.py — cmd_catalyst_timeline, cmd_catalyst_gate, _catalyst_tickers, catalyst 중첩 서브파서, events 임포트.
  • mcp-market-data/tests/test_events.py — 17개 오프라인 테스트(스텁 fetcher).
  • .claude/skills/catalyst-event-gate/SKILL.md — 신규 스킬 문서.
  • .claude/skills/expect/SKILL.md — Step 4 fetch, Step 5 ALGO 행, Step 7 RULE R3 + R1+R2+R3 스태킹.

회고

잘 된 점: fetcher 주입 덕분에 R3 규칙 전체를 오프라인으로 테스트할 수 있었음(17개 그린, 네트워크 없음); 페일-오픈 + 단일 fetch 할당량 가드는 기존 us.py 프로바이더 계약을 복사하는 것만으로 깔끔하게 나왔음. 앞으로 이어갈 것: KR은 선행 KR EPS 피드가 생길 때까지 구조적으로 매크로 전용; R3가 하드 날짜 계산에 사용될 경우 공휴일을 고려하지 않는 trading_days_between은 시장 공휴일 캘린더가 필요함.
