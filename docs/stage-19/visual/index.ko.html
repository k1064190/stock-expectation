19단계

이미 기록된 LIVE BULL 예측을 실제 시장 가격으로 재현해 실현 P&L, NAV 이력, 그리고 구체적인 알고리즘 튜닝 권고사항을 도출하는 모의투자 시뮬레이션 레이어를 도입합니다.

Paper Trading System

왜

Doctor Cho는 가상 자금으로 예측 알고리즘을 직접 거래해 성과를 측정하고 개선하고자 합니다. 시장별 시뮬레이션 계좌(미국 $100,000, 한국 ₩100,000,000)를 운영하고, 하루 단위 사이클로 최소 1개월 이상의 NAV/수익률을 기록하며, 알고리즘 튜닝을 권고하는 정기 자문 보고서를 생성합니다. 실현 P&L은 HIT/MISS 트랙레코드나 보정값이 근사적으로만 표현하는 진정한 성과 지표입니다.

무엇을

  • models.py — data/paper_trading.db 스키마 (accounts / positions / trades / nav_history) + 데이터클래스 + CRUD. CRUD는 커밋하지 않으며, 호출자가 트랜잭션을 소유해 하루 사이클을 원자적으로 처리합니다.
  • costs.py — 슬리피지(5 bps), 수수료(미국 0 / 한국 0.015%), 한국 매도세 0.18%.
  • strategy.py — 순수 함수 decide_entries(거래당 리스크 1%, NAV 대비 포지션 최대 20%, 하루 신규 최대 5개, 기본 손절 8%, 신뢰도 하한 0.60, 종목당 하루 1로트)와 decide_exits(목표가 / 손절가 / 보유 기간, 두 조건 동시 발동 시 손절 우선).
  • engine.py — run_day: 청산 → 진입 → 시가 평가 → NAV 기록을 하나의 커밋 트랜잭션으로 처리; (account, date) 기준 멱등성 보장; 데이터 공백 시 이전 평가액 이월.
  • review.py — 순수 지표 계산: 낙폭, Sharpe(표본 표준편차), prediction_id 기준 왕복 P&L 매칭, 신뢰도 귀속 분석.
  • scheduler/paper_trading_run.py — cron 실행 + --replay FROM..TO; 미국/한국 데이터 제공자 재활용; 벤치마크 = SPY / KODEX 200 매수 보유.
  • scheduler/paper_trading_review.py — 주간 자문 보고서 reports/paper-trading-review-YYYY-MM-DD.md (튜닝 권고 포함).
  • Cron: 매일 06:30 KST 틱, 매주 일요일 22:30 KST 주간 리뷰.
  • 부트스트랩 결과 (2026-04-04~06-22 재현, 약 54/52 거래일): 미국 +1.80%(Sharpe 0.61, maxDD −6.94%, 48 왕복, 40% 승률) vs SPY +13.4%; 한국 −1.92%(Sharpe −0.05, maxDD −12.5%, 63 왕복, 38% 승률) vs KODEX 200 +81%. 핵심 발견: 손절 청산이 목표가 청산보다 많고, 고정 목표가 방식이 상승 여력을 제한해 급등장에서 패시브 지수에 크게 뒤처집니다.

어떻게

  • 신호 소스 = predictions.db의 LIVE BULL 행(모두 목표가+손절가 포함). 당일 장 마감가로 체결(미래 데이터 사용 없음).
  • 예측의 거래소 현지 날짜(signal_local_date, UTC를 시장 시간대로 변환)를 해당 날짜 이후 첫 번째 거래 세션(effective_entry_date)에 매핑해, 한국 장전 07:00 KST 신호가 올바른 세션에 거래됩니다.
  • 순수 의사결정/지표 로직은 단위 테스트로 검증하고, 라이브 재현으로 연결부를 스모크 테스트합니다.
  • TDD 방식으로 개발: 신규 테스트 41개, 전체 스위트 641개 통과.

회고

  • 재현 기능은 즉각적인 효과를 냈습니다. 한 달을 기다리는 대신, 이미 기록된 예측에서 약 2.5개월치 NAV를 얻었고, 리뷰를 통해 구체적이고 실행 가능한 발견(목표가 청산 + 손절 청산이 추세 장세에서 뒤처짐)을 도출했습니다.
  • Codex의 시간대 오류 지적이 중요했습니다 — 한국 수익률을 양수에서 음수로 뒤집었습니다. 교훈: 저장된 UTC 타임스탬프는 체결 날짜를 확정하기 전에 반드시 거래소 현지 시간대로 변환해야 합니다.
  • 이월 과제: 자문 권고사항(신뢰도 하한 상향, ATR 트레일링 스톱, 규모보다 신호 품질 우선)이 알고리즘 개선 루프의 첫 번째 구체적 입력값입니다. 다음 단계는 그 중 하나를 PR로 실행하고 델타를 측정하는 것입니다.
