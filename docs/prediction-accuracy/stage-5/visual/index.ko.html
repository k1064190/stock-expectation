5단계

스캐너가 고른 각 종목에 전체 헤드라인 컨텍스트를 갖춘 독립적인 Bull/Bear/Judge 딥다이브를 부여하되, 기본적으로 꺼져 있는 플래그 뒤에 두고 그 자체로는 예측을 절대 기록하지 않습니다.

Deep Dive Fanout

왜

일일 브리핑은 한 번의 LLM 호출로 후보 5~6개를 분석하기 때문에 모든 종목이 얕고 공유된 컨텍스트만 받고, 대부분의 종목에서 /expect의 LLM_CONTEXT 노력도가 0으로 수렴합니다. 전체 헤드라인 세트와 자체 bin/stock-cli 접근 권한을 가진 독립적인 종목별 딥다이브(Bull/Bear/Judge)는 원샷 프롬프트가 가장 얕아지는 바로 그 지점에서 컨텍스트의 엄밀함을 끌어올립니다.

무엇을

scheduler/deep_dive.py는 엄격한 JSON 계약(ticker / context_score(-5~+3) / conviction / risks / catalysts / summary, 예측 기록은 명시적으로 금지)을 따르는 단일 티커 딥다이브 프롬프트를 실행하며, 제한된 팬아웃(ThreadPoolExecutor, 병렬도 2, 딥다이브당 420초, 최대 6개), 강화된 파싱(마지막 ```json 블록, ticker 일치 필수, 점수 클램프, conviction 화이트리스트, 리스트 정제), 종목별 fail-open을 갖추고 있습니다. daily_briefing.py에는 --deep-dive(기본값 off)와 --deep-dive-cap이 추가되었고, 결과는 각 딥다이브의 context_score를 해당 종목의 LLM_CONTEXT 필러로 채택하고 딥다이브를 그대로 components.deep_dive에 저장하라는 지시와 함께 브리핑 프롬프트에 주입됩니다. API 모드는 이 플래그를 무시합니다. 딥다이브는 그 자체로는 절대 예측을 기록하지 않습니다 — 단일 로깅 경로가 R1/R2/R3 규칙과 스토어 게이트의 권위를 유지합니다.

어떻게

TDD로 모듈 테스트 11개와 연결 테스트 2개를 먼저 작성했습니다. 서브프로세스 래퍼는 call_claude_code를 모방하지만 순환 임포트를 피하기 위해 deep_dive.py 안에 자체적으로 구현되어 있습니다. 기본 설정에서 최악의 실행 시간은 딥다이브 약 6개 × 워커당 최대 7분 ÷ 워커 2개로 마켓당 약 21분입니다 — 그래서 일주일간 수동 실행 결과가 괜찮아 보일 때까지는 기본값을 off로 둡니다.

코드 위치

  • scheduler/deep_dive.py — 전체 모듈
  • scheduler/daily_briefing.py — _deep_dive_block, build_claude_code_prompt 매개변수, run_briefing + argparse 연결
  • scheduler/tests/test_deep_dive.py, scheduler/tests/test_daily_briefing.py

검증

  • uv run pytest -m "not network" — 937개 통과 (신규 13개)
  • 실환경 E2E: NVDA에 대한 실제 claude -p 딥다이브 1건 성공 — 딥다이브가 자체적으로 stock-cli 데이터를 가져와 context_score +0.5 (MEDIUM)과 함께 구체적인 리스크 5개(방어적 1개월 섹터 로테이션, 변동성 비율 0.82에서의 주간 +8.3% 반등, ASIC 대체, 쏠림, 8/27 실적 발표 바)와 인용된 촉매 4개를 반환함 — 얕은 원샷 경로보다 훨씬 풍부함
  • --help 스모크 테스트에서 두 플래그 모두 표시됨

리뷰 루프

  • Antigravity (Gemini 3.1 Pro High): HIGH 1건 — 헤드라인이 딥다이브 프롬프트에 가공 없이 그대로 삽입되어 인젝션 표면이 됨; <headlines> 펜싱과 신뢰할 수 없는 데이터라는 지시, 회귀 테스트로 수정. MEDIUM 1건 — 대화체 서두가 붙은 순수 JSON이 폴백 파서를 실패시킴; 가장 바깥쪽 중괄호 구간으로 수정. LOW 3건 — null summary가 문자열 "None"으로 렌더링됨(수정), ARG_MAX와 고아 자식 프로세스 우려는 기존 call_claude_code와 동일한 패턴이라는 주석으로 문서화.
  • code-reviewer 서브에이전트: 모든 수정 확인; 경고 1건(다중 블록 파싱 미검증 — 테스트 3개 추가) + 제안 2건(문자열 내 중괄호 테스트 추가, 파싱 성공 시 디버그 로그 추가). "병합."
  • Codex: CLI와 GitHub 봇 모두 쿼터 소진 — PR-봇 라운드로 연기.

회고

딥다이브 자체의 데이터 접근 권한이 가치를 만든다 — 실제 NVDA 실행은 요청하지 않아도 섹터 상대강도, 거래량, 실적 캘린더를 끌어왔다. 일주일간의 수동 실행으로 비용 대비 품질 트레이드오프가 확립될 때까지는 기본값을 off로 유지한다.
